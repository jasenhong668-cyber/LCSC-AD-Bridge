# 新电脑安装与使用

## 安装

1. 在新电脑安装 AD 2024，用准备使用插件的 Windows 用户启动一次 AD，然后保存文件并完全退出 AD。
2. 完整解压本资料包到一个文件夹。不要在压缩软件内部直接运行 EXE，不要只复制其中某一个 EXE。
3. 双击 `LCSC_AD_Setup.exe`。
4. 选择插件安装目录、主库目录和 AD 2024 用户设置。只有一个符合条件的 AD 设置时会自动选中；有多个时请选择实际使用的那一个。检测不到时，先启动一次 AD 2024、退出，再点击“重新检测 AD”。
5. 点击“安装 / 修复配置”，等进度完成。“使用已有主库时，将其 IntLib 添加到 Components 面板”选项仅对已有编译库生效；新空库会在首次导入成功后自动生成和安装 IntLib。
6. 启动 AD，打开原理图、PCB、SCH Library 或 PCB Library。顶部“帮助”右侧应出现“立创元件”，点击直接启动插件。无需手动打开脚本工程。

默认安装在当前用户目录下的 `AltiumDocuments` 文件夹中。主库包含：

- `MyParts.SchLib`：原理图符号。
- `MyFootprints.PcbLib`：PCB 封装和嵌入 STEP。
- `MyLibrary.LibPkg`：仅引用上面两份源库，输出目录为 `Compiled`。
- `Compiled/MyLibrary.IntLib`：首次导入成功后由 AD 生成并安装，供 Components 面板使用；安装介质不预置这个文件。

空主库目录会安装两份空源库和空库工程，元件、封装和嵌入模型数量均为 0。使用已有库时必须有上述三份源文件，符号具有准确的默认封装和逐引脚映射，模型文件为 `MyFootprints.PcbLib`；若已有 IntLib，还会核对它与源库的绑定和 STEP 是否一致。检查失败时请先在 AD 修复、保存并编译原库，或选择新的空目录。

AD 打开空 SchLib 时可能自动创建一个 `Component_1` 空占位项。首次导入会自动清除符合 AD 默认内容的空占位项；已有引脚、图形、自定义名称或注释的内容会保留，不按空占位项处理。

插件目标目录应为空，或是由本向导安装的同一插件目录。已有手工便携包或其他程序目录不会被直接覆盖。路径支持空格；中文路径需当前 Windows 菜单编码能够表示这些文字。安装向导会检查不支持的字符，不能使用单引号、竖线或换行。

## 日常导入

1. 保存源库中尚未保存的编辑。
2. 点击顶部按钮，输入立创 C 编号或型号关键词，点击“搜索”。
3. 选择结果，检查原理图、PCB 和 3D 预览，以及封装、引脚/焊盘数量和 STEP 状态。
4. 点击“导入主库”。程序备份两份源库、库工程和集成库，合并符号与封装，设置默认 PCB 封装及引脚映射。
5. AD 原生保存源库、编译并安装同一份 `MyLibrary.IntLib`，逐项核对全部默认封装。以 AD 最后的保存、编译和封装检查成功提示为准。
6. 在 Components 面板选择 `MyLibrary.IntLib`，右键 Place 放置元件，按 AD 流程更新 PCB。已放置的旧元件需要在 AD 更新库内容后才会变化。

同编号重复导入不会新增同一条目。搜索/预览不会写主库。“导出模型”可将当前元件模型保存到新目录。关闭搜索窗口后可以再次点击顶部按钮。

进度条表示处理阶段，不是下载字节百分比；预览 100% 表示预览就绪。下载和几何转换有超时保护，失败会显示具体原因。几何修正处理来源的原点、缩放、Z/X/Y 旋转及 XYZ 偏移，不通过器件编号硬编码偏移。

## 重新配置与搬迁

保存并退出 AD，再重新运行资料包的安装向导。选择原安装目录与原主库目录，可修复顶部按钮、已有 Components 注册和路径配置。已有主库不会被空库替换或清空；安装器自己添加的菜单会更新为单份，保留其他菜单和已注册的库。

要迁移到新的插件目录，请让向导安装到新的空目录，并继续选择原主库目录。向导更新顶部按钮指向新脚本。旧程序目录可保留作为备份，确认新位置正常后再自行整理。

安装完成后，解压的资料包是安装介质，程序运行在向导选择的安装目录。不要单独移动已安装的 EXE 或 AD 脚本；需要换路径时重新运行向导。

安装器不会清空 AD 原有 Components 库列表，也不会复制原电脑的用户设置、缓存、下载任务或历史备份。
