# 立创元件导入 · MyLibrary 0.5 · 新电脑安装资料包

**2026-10-08 修复版：** 修复 AD 顶部按钮加载中文安装路径时误报“启动器缺失”的问题，并支持 AD 原生保存菜单后的重复安装。生成的脚本按本机 Windows ANSI 编码保存，安装完成前核对实际启动器路径。仍为 0.5 功能版本，初始库保持为空。

把本资料包整个文件夹复制到新电脑，先解压，再双击 **LCSC_AD_Setup.exe**。也可以双击 `安装.cmd` 打开同一个向导。

安装后，在 AD 顶部“帮助”右侧点击 **立创元件**，就会出现编号/型号搜索、检索结果和原理图、PCB、3D 三种预览。英文系统无法表示中文菜单时，按钮名称为 **LCSC Parts**，功能相同。

需要新电脑已安装 **64 位 Altium Designer 2024**，并用当前 Windows 用户启动过至少一次 AD。先保存文件并完全退出 AD，再运行安装向导。无需安装 Python。安装和使用同一个 Windows 用户，不需要修改 AD 安装目录。

向导会配置插件目录、两份空主源库、库工程和当前用户的 AD 顶部按钮。默认目录位于新电脑当前用户的 `AltiumDocuments` 文件夹，可以自行选择其他目录；不要求有 D 盘或 E 盘。首次成功导入后，AD 自动编译并安装集成库到 Components 面板。

**全新安装使用空库：符号 0 个、封装 0 个、嵌入模型 0 个。** 不附带原电脑的任何元件、STEP 或已有 IntLib。新元件通过联网搜索、下载和导入，符号与封装自动绑定，STEP 嵌入到 PCB 库。若用户主动选择已有完整主库，安装器进行校验并保留该库，不清空其中元件。

请先看 [安装与使用说明](安装与使用说明.md)。遇到安装失败或需恢复设置时看 [故障与恢复](故障与恢复.md)。功能说明在 `runtime/功能说明.md`。安装结果和备份路径由向导显示，并记录在安装目录的 `安装结果.json`。

资料包面向 AD 2024。其他 AD 大版本尚未作为安装目标验收。当前验证包括本机 AD 24.5.1、冻结可执行程序的路径迁移、隔离安装、重复安装、菜单保留和恢复；未冒充真实第二台电脑测试。详细记录见本包 `验证记录`。
